Prebuilt MediaTek Dimensity 8300-Ultra (MT6897) kernel tree for Xiaomi 14T (*degas*).

## Contents
* `Image.lz4` - Compressed GKI Linux kernel image
* `dtb/` - Device Tree Blobs for MT6897 platform
* `dtbo.img` - Device Tree Blob Overlay image
* `kernel-uapi-headers.tar.gz` - User-space API kernel headers
* `modules/` - Kernel loadable modules (`.ko`)
